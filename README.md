# Issue Tracker

Sistema de gestión de incidencias para equipos de soporte técnico.

## Tecnologías
- React.js + Vite
- React Router DOM
- Tailwind CSS
- SweetAlert2
- MockAPI

## Instalación

```bash
npm install
npm run dev
```
